# 英文输入模式实施计划

状态：核心实现已落地并热加载，默认关闭；4次隔离真实翻译/发送检查完成，使用与边界见[英文模式说明](<C:/Users/WestFox/.dsh/plugins/dsh-prompt-optimizer/docs/ENGLISH-MODE.md>)。能力收益待用户实际对照。界面保持中文；不添加回复中文/回复英文的额外控制，用户自己写的语言要求忠实翻译。默认关闭，会话覆盖优先。

## 目标

转换本插件的优化指令、用户当前任务、生成的辅助和注入标题/协作协议为英文。用户原始文本作为来源与授权依据单独保存；实际发送的英文文本可查看与回退。语言模式与提示词辅助、推理增强各自独立。不以英文模式宣称能力收益已测。

## 实现

1. 新增englishMode设置，默认false，支持bySession，现有换档保留它。关闭时走现有路径。
2. 新增静态英文解释契约、协作/工具说明和按档位生成的英文策略。自定义解释提示词不改原文件，英文副本按原文哈希、模型路由、版本缓存。
3. 输入先保护代码围栏、行内代码、路径、URL、显式逐字字符串及数字；模型输出占位符，恢复时核对数量与内容。语义保真仍需要可见译文，机械检查不能证明完整等价。
4. 开启辅助时同一次解释返回englishTask，ops与机器理解直接英文；引文仍从原话逐字引用，englishQuote仅是原话摘录的翻译，不是新增要求。字段与来源分离保存。
5. 辅助关闭时用同一个解释路由的轻档专门翻译，禁用工具，不增加单次输出上限。明显已是英文/纯保护内容不额外调用。
6. 编译器/能力投影/顾问协作协议使用英文标题和提示。失败日志、引用原文、路径等原始证据保留。推理增强的选择/反馈系统和改进提示跟随englishMode。
7. 发送前拦截独立于辅助off，使用宿主setDraft/submit。确认与自动发送采用英文；取消/按原文发送保留原文。斜杠命令直接留给宿主，附件不变。
8. 原文与译文绑定会话+输入事务，真实提交英文时不会误认成新任务或重解释。翻译迟到/开关变化/取消不允许发送旧译文。
9. 审查面板显示原文、英文任务、英文辅助与翻译耗时；无辅助增量仍可翻译成功。翻译失败走既有自动原文回退/审查停留并说明。

## 覆盖与边界

首版覆盖GUI发送前路径及本插件模型指令，不改宿主冻结请求、旧对话、工具返回、其他插件或第三方服务的语言。不覆盖用户原文件。不改变权限、工作模型或答复语言。
