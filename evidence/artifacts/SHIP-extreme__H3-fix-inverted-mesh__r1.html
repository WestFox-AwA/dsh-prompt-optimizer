操作提示
KeyW / ArrowUp  : 前进
KeyS / ArrowDown: 后退
KeyA / ArrowLeft: 左转
KeyD / ArrowRight: 右转
KeyQ / KeyE     : 炮塔左/右偏转
鼠标移动       : 转炮塔 (X) / 俯仰 (Y)
点击画布       : 请求指针锁定
Escape          : 退出指针锁定
BracketLeft   : sensitivity × 0.5
BracketRight  : sensitivity × 2
KeyY            : 反转 Y 轴 (invertY)
