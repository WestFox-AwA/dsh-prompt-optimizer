把 gateway 的端口从 8000 改成 7070：

- `config.json:3`：把 `"port": 8000` 改为 `7070`（入口就是这一处）。
- `README.md:3`：此处同样出现 8000，一并同步为 7070。
- 全项目搜索 `8000` 只命中上述两处，不要改动其他位置；若发现按 8000 拼接地址的硬编码，同样只改端口号为 7070，并保持原写法。

【当前仓库快照（受上下文预算限制，可能只给出一部分文件）】
--- app.mjs ---
import { readFileSync } from 'node:fs'
const cfg = JSON.parse(readFileSync('config.json', 'utf8'))
export const port = cfg.port
if (port !== 7070) { console.error('port mismatch: ' + port); process.exit(1) }
console.log('gateway listening on ' + port)

  "name": "gateway",
