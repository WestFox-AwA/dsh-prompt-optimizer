# 产物级（单文件 HTML）验证：`html-verify.cjs`

**思路**：不依赖浏览器（本会话 Edge 无法无头渲染），改为"纯计算沙箱 + 独立审计"——
把产物里的脚本抽出来在 Node 沙箱里执行，**由验证器自己**从 `buildGeometry()` 取几何、计算每个三角面的法线朝向，
再与质心方向比较，得出 `inwardFaces / facesOutwardRatio`。产物自报只作次要证据。

**验证器自证（必须一直保持）**

| 夹具 | 期望 | 实测 |
|---|---|---|
| `html-fixtures/gold.html`（按"从外看逆时针"构造六个面） | PASS | **15/15 PASS**，独立审计 12 面 / 内向面 0 / 比例 1 |
| `html-fixtures/bad.html`（同一几何，索引绕序整体反转） | FAIL | **FAIL**，独立审计 12 面 / **内向面 12** / 比例 0 |

**真实产物（`lab-html.json`，staging 工具 `cxlab` mode=artifact，执行 AI 直接产出单文件 HTML）**

| 题 | 条件 | 结果 | 独立审计 |
|---|---|---|---|
| H1 坦克盒体（法线与可见面） | 发布版 0.2.2（极端档） | PASS 15/15 | 12 面 / 内向面 0 |
| H1 坦克盒体 | v0.3（极端档） | PASS 15/15 | 12 面 / 内向面 0 |
| H3 审计并修复反向面网格 | 发布版 0.2.2 | **FAIL 10/13** —— 产物脚本有 **JS 语法错误**，无法解析 | 无法审计 |
| H3 审计并修复反向面网格 | v0.3 | **FAIL 11/13** —— `buildGeometry` 未暴露到全局 | 无法审计 |

**结论（本轮）**：H1 太简单、两个条件都过 → 不具区分度；H3 有区分度（发布版产物直接语法错误），
但两条件都没满足"可自动化验收接口"，说明**验收接口目前只写进了执行 AI 的提示，没写进用户原话**——
评分卡却要求优化器写出来，这对优化器不公平。

**待办（下一轮）**
1. 验证器兜底：`buildGeometry` 未暴露时，按花括号配对从脚本文本里抽出函数体单独求值；再退一步用 `__selftest()` 自报数据。
2. 任务规格公平化：把"必须暴露 `buildGeometry()` / `window.__selftest()`（含修复前后计数）"写进**用户原话**，
   这样"命令是否把验收接口带下去"才是优化器真实的得分点。
3. 产物题扩容：H2 操控人性化（键位/灵敏度/退出捕获/提示）也接进产物级验证；每题两条件各跑 2 次以评估稳定性。
