## 一句话

你照常说话，它在你发送**之前**替你把"这一轮到底要什么"理清楚，再把这份理解交给工作 AI ——
**你的原话不会被改写，也不会被丢掉**。

## 怎么用（三步）

1. 像平时一样在输入框里打字。
2. 按回车 / 点发送 —— 消息会**先停一下**，等它把这一轮想清楚。等待期间面板上**能看到它在做什么、正在写什么字**（不是干等一个进度条）。
3. 它想完就把你的**原话**发出去；工作 AI 从**这一轮的第一步**就带着这份理解，不用等到下一轮。

不想等？「优化中」随时点 **跳过并直接发送**。

> 万一它这次没想出来（模型不可用等）：**「自动」档**会按你的原话发出并在面板上说明原因；
> **「审查」档不会自动发出**，面板会停在错误态等你自己决定（点「按原文发出」或「重试」）——消息一直躺在输入框里，不会丢。

## 面板上的开关怎么选

**档位**（关闭 / 轻度 / 标准 / 重度）

- **关闭**：完全不拦、不解释、不等 —— 跟没装一样（想临时关掉就用它）。
- **轻度**：把原意讲得更清楚，消除易误解的指代、范围和条件，指出必要反问。
- **标准**：**推荐**。澄清表达，再补足对结果影响最大的缺口与关键建议。
- **重度**：围绕已有目标全面寻找正向补充、构思和做法，说明未定前提与重要取舍，给出必要反问。
- 三档都以**不扭曲用户原意**为权威，不以条数、字数或固定流程区别。思考档位独立设置，短协议不会自动把 Max 调低。

**优化权限**（审查 / 自动）

- **自动**：它一完成就直接把你的消息发出去（你只需要等解释那一次）。
- **审查**：它完成后**先给你看**这一轮要注入的内容，你可以**直接改**，满意了再点「确认提交」；不想用它就点「按原文发出」或「跳过」。**这一档永远不会替你自动发出**——包括解释失败的时候。

**英文模式**（关闭 / 开启，默认关闭）

- 开启后，**你这一轮的任务、优化策略与辅助文会先转成英文**再送给模型——界面与状态仍是中文（状态里的要求正文回到你的原话）。
- 代码块、路径、URL、JSON 字面量与**逐字引用的原话**不会被翻译；`/` 开头的命令也不翻译（名单内的命令照旧走拦截审查）。
- **它不替你要求答复语言**：模型用什么语言回答，仍由你的原话决定；要中文就说一句。
- 代价是每轮多一次翻译调用（有缓存），所以默认关闭。

**内置 Bash 是 Windows 专用**（随包分发的是 Windows 版 MSYS2 运行时）；非 Windows 平台上模型拿不到这个工具。

**推理增强**（实验性，默认关闭）

- 在面板最下面的「实验性功能」分界线之下。开启后，一次生成可能变成多次调用（多候选择优 / 循环改进 / 混合）。
- 「推理过程」面板只在开启后出现：能看到每一次调用、耗时，以及最后采用的是哪一份。
- ⚠ **目前无法确定它能否稳定提升模型能力，但会让模型的工作时间大幅增加**——请谨慎开启，并用同一任务对照开关前后。

**上下文**（回合 0~10 / 全文）

- 它解释时会参考你**最近的几轮对话**，读得越多越懂你在做什么，也越慢。
- 切到**全文**就是"我这边留着的都读"，滑块变成**关 / 开**两格（关 = 完全不读）。
- 拿不准就用默认：**回合 6** 左右。

**读项目文件**（开 / 关）

- 打开后，它可以在**你的工作目录内**翻几个文件来核对事实（只读、不写、不执行命令）。
- 代价是**更慢、更费 token**；所以默认是**关**。要它"少猜、多照实说"的时候再开。

## 界面上的几处

- **详情**：左边的灰绿小灯是状态（自动 / 只记录 / 未启用）。点「详情」能改**解释用的核心提示词**（也能撤销上一次修改、恢复内置）。短协议区分当前设置的完整组合预览与本会话最后实际发送的协议，并显示字符数、思考档位。
- **`?`**：就是你正在看的这个。
- **浮层**：拦截期间出现的小窗口。可以拖动（拖标题）、可以拉右下角改大小、点右上角收起成小圆球，需要时再点开。

## 推荐组合

| 场景 | 建议 |
|---|---|
| 第一次用 | 档位 **标准** + 权限 **审查**（能看清它到底做了什么） |
| 日常干活 | 档位 **标准** + 权限 **自动** |
| 快到飞起 | 档位 **轻度** + 上下文 **回合 2~4** |
| 复杂/易误解的活 | 档位 **重度** + 打开**读项目文件** |
| 只想记一笔 | 档位 **关闭**（不拦、不等、不改任何东西） |

## 常见疑问

**会等多久？** 一般 20~60 秒（取决于档位、上下文、模型）。这段等待就是它"替你想清楚"的时间。

**我的消息会被改吗？** 不会。被改的是**它给工作 AI 的那份理解**；你发出去的字还是你写的。

**会不会把我的消息弄丢？** 不会。万一它出错或想不出来，会**直接按你的原话发出**，并告诉你原因。

**它会记住上一轮的目标吗？** 不会——每一轮都按**你这轮的原话 + 最近的上下文**重新想一遍，
上一轮的目标不会带进这一轮。所以你**不会**看到"上一轮早就解决的事又被要求一次"。
代价是**长期约束也要靠上下文每轮重新看出来**：像"只交单个文件""别动别的文件夹"这种要求，
如果它这轮读的上下文里已经看不到，就不会被写进这一轮的理解里——所以别把**上下文**关得太小。

**它会替我编要求吗？** 会尽量只写你说过的和能从上下文看出来的。真出现"没有出处"的条目，审查界面会**红字警告**你。

**读项目文件会不会动我的东西？** 不会：只能读、限定在你的工作目录内、越界一律拒绝。
