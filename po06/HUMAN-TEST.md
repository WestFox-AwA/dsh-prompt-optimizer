# 一次跑完的人工验收清单（0.6.6）

> 你只需要**照着做一遍**，把「实际看到什么」回给我；不用你判断对错，也不用你改任何东西。
> 前提：**档位不能是「关闭」**——「关闭」档按设计不拦截、不解释、不注入，那是 0 等待的原生路径。
> 建议档位 = **标准**，权限先设 **审查**（能看清全过程），跑完再试一次**自动**。

| # | 你要做的 | 期望看到（如果不一样，请把实际现象原话告诉我） |
|---|---|---|
| 1 | 确认控件栏：档位拨到**标准**、权限**审查** | 控件栏两行；第一行 = 档位 / 权限 / 模型 / `?`；第二行 = 上下文 / 读项目文件 / 详情 |
| 2 | 点 `?` | 弹出帮助，正文**不再说"下一轮才生效"**；第 1 节讲的是"消息会被先拦下" |
| 3 | 上下文点「全文」 | **滑块变成只有两格**（关 / 开），右边数字显示 `关` 或 `开`（不再是 0~10） |
| 4 | 点回「回合」 | 滑块恢复 0~10 量程，右边数字恢复裸数字；**你原来的回合数没被改掉** |
| 5 | 点行尾「详情」 | 按钮文字就是**详情**，前面有**灰/绿状态灯**；面板里**只有「控制」与「解释层提示词」，没有「它在替我做什么」「最近几轮」** |
| 6 | 在输入框打一句话（例：`帮我把这份配置检查一遍，先给结论`），按**回车** | **消息没有立刻发出去**；出现浮层：「优化中… 已用 N 秒」+ **跳过并直接发送**，并且**能看到它在做什么**（阶段：判定启用 → 解析模型路由 → 读上下文 → **正在写这一轮的理解**，下面还有正在写出的字） |
| 7 | 等（实测 20–60 秒；期间面板不该消失） | 面板变成**审查态**：可编辑的正文（就是本轮要注入的内容）+ 底部按钮：**确认提交 / 按原文发出 / 重新生成** |
| 8 | 在正文里**改一行**，点**确认提交** | 你的消息**这时才发出去**；本轮工作 AI 看到的就是**你改过的那份**（可以问它"我这轮的要求是什么"来核） |
| 8b | 另发一句，等它进入审查态后先**不点任何按钮**，放 1 分钟 | 消息**一直不发出**（审查档不会替你自动发送）；想放弃就点「按原文发出」或「跳过」 |
| 9 | 再发一句，这次按回车后点**跳过并直接发送** | 消息**立刻发出**（不等解释） |
| 10 | 权限改**自动**，再发一句 | 解释完成后**自动放行**（不需要你点确认），面板短暂显示后消失 |
| 11 | 最后把档位拨回**关闭**，发一句 | **完全不拦、不等待**，和没装插件一样 |
| 12 | 打开本会话的**设置页 → 插件 → 提示词优化器** | 「最近几轮」还在（那是插件的设置面）；能看到每轮读取的上下文/包字数与耗时 |

## 需要你反馈的四件事

1. **哪一步的现象和期望不一样**（原话描述即可，不用解释原因）。
2. 第 6–8 步：**面板会不会中途消失**、**消息会不会自己跑出去**（这是上一版的两个真 bug，已修但未真机确认）。
3. 第 12 步：**工作 AI 是否真的"第一步就吃到"**——最好在同一个会话里另开一句问它"我这一轮的要求是什么、依据是什么"。
4. 如果你还想压测：把「读项目文件」打开再走一遍第 6–8 步（它会多花时间与 token）。

## 已知且**不打算**在这次里解决的（免得你以为是 bug）

- 首次进入某会话时，面板出现前的等待就是解释层的真实耗时（**不设超时**是你的选择）。
- 「详情」面板里**没有**逐条意图与出处列表（按你要求撤掉了）；"无出处条目"的警告挪到了**审查面板**里。
- 拦截**只在网页输入框里生效**：终端/其它客户端发的消息仍走"零延迟"旧路径（第 2 步起生效）。
