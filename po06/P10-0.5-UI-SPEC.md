# P10 参考 · 0.5.2-beta.1 UI 与行为规格（逐行提取，供 0.6 对齐用）

> 来源：`dsh-prompt-optimizer-0.5.2-beta.1/package/lib/client.js`（[C]，4536 行）与 `lib/index.js`（[H]，4094 行）。
> 用途：0.6 要做成**同样的操作形态**。本文件是**参考**，不是照抄清单——末尾「红旗」列出 0.5 自身的缺陷，**不要复刻**。

## 1. 挂载点（0.6 现在错在位置）

| 部件 | slot | id | order |
|---|---|---|---|
| 输入框左侧控件 | `conversation.input.left` | `prompt-optimizer` | 20 |
| 浮层 | `shell.overlay` | `prompt-optimizer-overlay` | 60 |

- `exports.inject = ["slots", "locale"]`（[C:2994]）。
- **slot 按 id 去重**：同 id 重注册会抛 `list slot "…" already has an entry with id "…"`，**改 order 绕不开**；
  自愈重挂前必须**先 dispose**（[C:3672-3701]，控件 1200ms×8 次、浮层 1500ms×6 次）。
- 语言：`L(zh)` / `Lf(zh, params)`，字典**键＝中文原文**；`locale.active` 以 `en` 开头则英文（[C:282-292, 3650-3664]）。

## 2. 输入框左侧控件（DOM 顺序 = 视觉顺序）

`tier` → `perm` → `turns`（含模式切换按钮）→ 分隔线 → `model` → `?` → 弹层 → toast

### 2.1 档位（分段胶囊，可点/可拖/可方向键）
- 容器 `div.dpo-controls[data-dpo="controls"]`，高 26px；档位元素 `[data-dpo="tier"]`，宽 128px（窄屏递减）。
- **可见文字就是四个档位名**；当前值另写入 `[data-dpo="tier-value"]`，但该元素用 `clip-path` **视觉隐藏**（只给探针/读屏）。
- 交互：按下按格取 `floor(t*n)`；拖动（pointer capture）；`←/↓` 上一档、`→/↑` 下一档、`Home/End` 两端。
- tooltip = `提示词优化档位：关闭 / 普通 / 高级 / 极端（点击/拖动/方向键；当前：普通）`。
- 窄屏（≤1240px）折成单按钮 `[data-dpo="tier-collapsed"]`，文字 `档位` + 当前档名。

### 2.2 权限（分段胶囊，宽 84px）
- 可见文字 `审查` / `自动`；**档位为「关闭」时禁用**（`data-disabled="true"`、`tabIndex=-1`、title 换成 `档位为「关闭」时不生效`）。

### 2.3 上下文（量程胶囊 + 模式切换按钮）
- 轨道拖动 / 键盘（`←→` ±1，`Shift` ±10，`PageUp/Down` ±10，`Home/End`），数字显示**裸数字**（回合模式）或 `关/开`（全文模式）。
- 模式按钮 `[data-dpo="turns-mode"]`：文字 `回合` / `全文`；点击 `stopPropagation` 防误拖；切换时弹 toast。
- tooltip（回合）：`读入最近 0~10 回合对话作为意图上下文（0 = 不读；只读用户侧信息，工作 AI 回复只留长度）（拖动 / 点击 / ←→；当前 N 回合）`
- tooltip（全文）：`全文：把工作 AI 现在看到的完整上下文（双方全文）交给优化模型；受 6 万字符总量上限约束，超限整回合省略（两档：关 / 开）`
- **档位为「关闭」时禁用**。

### 2.4 模型胶囊 / 帮助
- 模型：`button.dpo-model[data-dpo="model"]`，文字 = 模型名或 `会话默认` + caret `▾`，title `优化所用模型（与对话模型独立）`。
- 帮助：`button.dpo-help`，文字**就是一个 ASCII `?`**，title `使用帮助（怎么用 / 档位 / 权限 / 推荐组合）`。

## 3. 浮层（`shell.overlay`）内部顺序

头部（可拖）→ 滚动区 `[回退确认条 → 运行状态行 → 思考折叠 → 产出 → 审查 textarea → 原文折叠 → 查证折叠]` → **常驻底栏**（在滚动区外，按钮永不被滚走）→ 右下角缩放柄；关闭后收成 46px 悬浮球。

- 状态行：`优化中…` / `已完成` / `失败` + ` · 首字 {ms}ms` + 上下文 chip（`上下文 N 回合 · M 字`）+ `Σ {tok} tok`。
- 思考折叠：默认「运行中展开、完成后收起」（用户点过则以用户为准）；无 token 时显示 `— tok`（title `该 provider 未上报思考 token`）。
- 产出：`done && permission==="review"` 时**不渲染只读产出**，改由 textarea 承载（`以下内容将原样发给工作 AI（可直接编辑） · N 字`）。
- 底栏五种变体（首个命中生效）：`foot-regen` / `foot-sent`（`已发送 · 仅供查看` + `关闭` + `重新生成`）/ `foot-review`（`‹ 回退` + `确认提交` + `重新生成`）/ `foot-error`（`重试` + `默认模型重试` + `按原文发出`）/ `foot-idle`（`‹ 回退` + `放行本条（按原文发出）`）。
- 错误：**内联一行**，`失败：` + 人话化文案，原始错误全文放 `title`；映射表覆盖 `NO_ADAPTER / ABORTED / no-llm-route / 401 / 429 / timeout`。

## 4. 持久化契约（0.6 现有字段名可保留，语义要对齐）

恒定上报 `{tier, permission, model, reasoningEffort, sessionId, turns, historyMode, fullOn}`；
**三态字段**：`readTools` 与 `delivery` **仅当用户显式选过才上报**——`null`（还没从宿主读到）时绝不上报，
否则会把"未设置（默认开）"误写成显式 `false`（[C:318-321]）。

## 5. 控件真实行为（读宿主确认）

### 档位
| 档 | 宿主行为 | 工具 |
|---|---|---|
| `off` | **客户端根本不发给宿主**：拦截前改写为 `basic`，并 `armed=false` ⇒ 完全不拦截 | — |
| `basic`/普通 | 只做语言层（原意/范围/篇幅不变，≤1.5× 原话），提问 ≤1 | **永不派工具** |
| `advanced`/高级 | 只补三样（对象/结果/边界），≤2.5×，提问 ≤3 | 可派 |
| `extreme`/极端 | 0.4.4 极端档正文一字不改 + 歧义就问用户，≤4×，提问 ≤5 | 可派 |

### 上下文（喂给优化模型的方式）
- **注入在 system**（不是 user 消息），块首声明**旁观者身份**（"你不是执行者，这不是用户对你的要求"）。
- 回合模式：从投影**从末尾往回数 N 个用户回合**；`turns<=0` 直接不读。
- 全文模式：整段投影，行数超 240 丢最早的行并写明。
- 上限：回合 12000 字 / 全文 60000 字；单条用户 ≤4000、全文模式单条助手 ≤8000。
- **超预算走"只降详细度、不动范围"的 5 级阶梯**，每级标签写进注入文本。
- ⚠ `historyMode:"full"` 且 `fullOn:false` ⇒ 实际发 `historyMode:"off"`（**完全不读**，不是"读少量"）。

### 只读工具
- 三个：`read{path,startLine?,endLine?}`（默认 200 行、文件 >200KB 拒绝、结果 >4000 字截断）、
  `glob{pattern}`（≤50 命中、≤400 文件、深度 ≤6、跳 `node_modules/.git/dist/build/.next/evidence` 与点文件）、
  `grep{pattern,path?}`（≤40 命中，`文件:行号: 内容`，内容截 200 字）。
- 越界：`resolveInsideRoot` 词法 + `realpath` 双校验，越界回 `拒绝：路径越出项目范围（只读工具限定在项目根内）`。
- **三重与条件**：`档位∈{高级,极端}` ∧ `readTools===true` ∧ **能解析到本会话 cwd**；解析不到就**不派工具**
  （"宁可少读，也不读别的会话的目录"）。
- 轮次：正式运行 `maxRounds: 5`（模块常量 `LOOP_MAX_ROUNDS=6`、`LOOP_BUDGET_MS=90000`）。
- trace：每轮工具调用**实时**下发（`{round, tool, args, ok, ms, resultLines}`），客户端保留最后 12 条。

### 权限（重要）
**permission 是纯客户端行为**：宿主只存不算（`executeLiveRun` 从不读它）。
`review` = 完成时不自动发送、产出放进可编辑 textarea、点「确认提交」才发；
`auto` = 完成即发，**出错/空产出也 fail-open 按原文发出**。

## 6. 红旗：0.5 自身的缺陷，0.6 **不要**照抄

1. **`run.id` 从未赋值**（客户端只有 `run.runId`）⇒「成了 / 要返工」按钮**永不渲染**，`/outcome` 永不发出
   —— 即"一次交付可用率"这个唯一目标指标在 0.5.2 里**实际未接通**。
2. `historyMode:"full"` + `fullOn:false` ⇒ 发 `"off"`（完全不读），与 UI 暗示不符。
3. 回合模式文案说"工作 AI 回复只留长度"，实现默认策略下**带的是助手全文**。
4. 帮助里的压缩阶梯（"缩到最近 4/2 回合"）与实现的**5 级详细度阶梯（不缩范围）**不一致。
5. `/trace` 读的是**上一次自检**落盘的数据，真实运行靠 SSE；两套并存且 UI 不区分。
6. 工具循环降级（`toolLoopError`）**UI 无任何提示**。
7. 署名硬编码 `0.4.6beta4`，与包版本 0.5.2-beta.1 不一致。
8. `readTools` / `delivery` 的**三态语义**放弃不得（见 §4）。
9. 英文档位名是 **Low / High / Ultra**，不是 Basic/Advanced/Extreme。
10. 客户端**不用 `console.*` 报错**，异常一律走 beacon（`window.onerror` / `unhandledrejection`）。

## 7. 0.6 要复刻的最小清单

`conversation.input.left`(order 20)：档位分段胶囊 + 权限分段胶囊 + 上下文量程胶囊(含模式按钮) + 分隔线 + 模型胶囊 + `?` 帮助；两个 fixed 弹层（模型 / 帮助）；一个 toast。
`shell.overlay`(order 60)：可拖可缩面板 = 头部(标题+档位 chip+拦截计数) / 滚动区(回退确认 → 状态行 → 思考折叠 → 产出 → 审查 textarea → 原文折叠 → 查证折叠) / 常驻底栏 / 缩放柄；关闭后 46px 悬浮球。

**本阶段不做**（用户已定"只对齐操控形态"）：`run/outcome/trace` 检视面、执行端 PTC/对话式/自动、思考强度档。
