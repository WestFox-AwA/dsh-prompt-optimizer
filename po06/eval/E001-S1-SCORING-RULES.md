## 问题一：「请你决定 X」与「提醒你 X 会有后果」到底怎么分？

区别在**这句话要你交出什么**：

| | 它要你做什么 | 该不该算"不该问" |
|---|---|---|
| **请你决定 X** | 要你**选一个影响交付物的东西**，而 AI 无从知道 | 看 X 的性质：**偏好/范围** ⇒ 该问；**可查事实/可逆实现细节** ⇒ 不该问 |
| **提醒你 X 会有后果** | **不需要你回答**——AI 已经定了怎么做，只是告诉你"这么改会连带影响 Y" | **不该勾**（它不是提问，见问题三） |

举两个你表里的真实例子（H-09：把 `MODES` 顺序改成 `['all','allowlist','off']`）：

- 「这个数组的顺序会不会被别处当成**优先级/默认值**来用？」→ 这是**可查事实**（读一眼代码就知道），
  所以它属于**不该问** → `[x]`。
  *（但注意：本实验**没给模型工具**，它读不了。所以严格说这是"本条件下只能问"——见下面的说明。）*
- 「改完后默认模式会从 `off` 变成 `all`，这可能是你想要的，也可能不是——确认一下是否该显式写成
  `DEFAULT_MODE='off'`」→ 前半是**提醒后果**，后半是**要你定一个影响行为的选择**。
  这种"提醒 + 附带一个决定"的混合句，按**它要你回答的那部分**判：如果那个决定是
  **偏好/范围** ⇒ 该问（不勾）；如果是**可逆实现细节** ⇒ 不该问（`[x]`）。

**一句话记法**：问自己"**答完之后，AI 还需要我吗？**"
需要（只有我能定）⇒ 该问；不需要（它自己能查/能定）⇒ 不该问。

## 问题二：本实验"没给工具"这件事要怎么处理？

这是你要知道的一个背景，否则会对一批问句判得偏重：

- S1 的对照里**两臂都没有工具**（不能读文件、不能跑命令）。所以"你能查一下 X 吗"这类，
  在本实验里**问是唯一诚实的做法**——不问就只能编。
- 而你日常用的工作 AI **是有工具的**。

所以我建议用**两档**来区分，而不是一刀切：

| 标记 | 含义 | 怎么算 |
|---|---|---|
| `[x]` | **不该问**：即使有工具，这也该它自己定（可逆实现细节、它自己能决定的事） | 计入"不该问" |
| `[!]` | **只好问**：属于可查事实，但**本实验无工具**，问是不得已 | **另计**，不计入"不该问" |

> 如果你觉得分两档太麻烦，就统一用 `[x]` 也可——我会在结论里注明
> "其中若干条属于无工具条件下的不得已"，不会把它当成产品缺陷。

## 问题三：那些**根本不是提问**的条目怎么评价？

`[ ]` 列表里确实混进了非提问句（我的抽取是启发式的）。典型三类：

1. **纯陈述**：「声明关键字和变量名保持不变（原来是 `const` 还是别的形式，都只动方括号里的内容）」
2. **提醒/警告**：「有 CI 发布步骤 → 这个改动会让发布任务失败」
3. **要你干活/贴资料**：「你把那段贴过来，我可以给出精确 patch」

评价方式：**不改动它**（保持 `- [ ]`）就不要紧——但为了让我算准分母，请把它们标成：

```
- [-] 
```

**`[-]` = 不是提问** ⇒ 不计入分母（既不算该问，也不算不该问）。这样它就不会污染比例。

## 你新加的 `c-xxx`：重复项（**语义重复**，不是字面重复）

已确认你的定义：`c-xxx` 表示"**与第 xxx 条在本质上问的是同一件事**"——
措辞可以不同，但**指向同一个决策 / 信息熵几乎一致**。这是**语义去重**，比字面去重严格得多，
也更有用（字面重复一眼可见，语义重复才反映"到底问了几件不同的事"）。

写法与我的解读：

```
- [ ] **C12** · ... （原句）
- c-A07            ← 与 A07 是同一个问题（跨臂）
- c-C03            ← 与 C03 是同一个问题（同臂内）
```

- **不计入分母**（同一件事只算一次）——否则"同一个疑问换三种说法"会平白把比例拉高。
- **按被引用者的臂自动分两类**，我会分开报，因为含义不同：
  - **臂内重复**（`c-Cxx`）= **C 自己在换着说法重复同一件事** ⇒ 这是"噪声/复述"信号；
  - **跨臂重复**（`c-Axx`）= 这件事**两臂都问了** ⇒ 说明它**不是 0.6 带来的**，对比较没有区分力。
- 只写 `c-12` 而 A12/C12 都在时：**按你所在的那一臂**解释；写全 `c-A12` 最保险。
- 如果你想表达"**这一组**其实是一件事"（三条以上互为重复），写成
  `c-C03,C11`（与那两条都是同一个问题）即可，我按并查集合并成一组。

> 因为这是**你的语义判断**，我不会用任何自动方法去猜重复——只按你标的算。
> 我也会把它记为"用户判读"，而不是机器结论。
